# Events Bot

Бот парсит Telegram-каналы, находит мероприятия и сохраняет в каталог.

## Переменные окружения (Railway → Variables)

| Переменная | Значение |
|---|---|
| `GEMINI_API_KEY` | Ключ от aistudio.google.com |
| `DB_PATH` | `events.db` |

## Что делает бот

- Парсит 75+ публичных Telegram-каналов
- Анализирует каждый пост через Gemini 1.5 Flash
- Определяет: мероприятие/не мероприятие, дата, время, платно/бесплатно, для детей, формат (офлайн/онлайн), тематика
- Исключает дубликаты
- Запускается каждые 6 часов автоматически

## Деплой на Railway

1. Загрузи все файлы в GitHub репозиторий
2. Railway → New Project → Deploy from GitHub
3. Добавь переменную GEMINI_API_KEY в Variables
4. Deploy
